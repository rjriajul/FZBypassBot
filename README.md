## ***Terabox Setup***

Terabox DDL generation supports two modes. **Both can be set simultaneously** — the bot tries the API first and falls back to the cookie automatically.

### Option A — Cookie (Direct, No Extra Service)

1. Open [terabox.com](https://terabox.com) and log in
2. Open DevTools → Application → Cookies → `terabox.com`
3. Copy the value of the `ndus` cookie
4. Set in your config:
   ```
   TERA_COOKIE = your_ndus_value_here
   ```

### Option B — Self-hosted API (Recommended for high volume)

Deploy the [terabox-downloader-api](https://github.com/MeherMankar/terabox-downloader-api) as a separate service, then point the bot at it.

1. **Deploy the API:**
   - Click the Render deploy button in the [terabox-downloader-api](https://github.com/MeherMankar/terabox-downloader-api) repo
   - Set `TERABOX_COOKIE = ndus=your_ndus_value` in its environment variables
   - Copy your deployed API URL (e.g. `https://your-api.onrender.com`)

2. **Point the bot at it:**
   ```
   TERA_API_URL = https://your-api.onrender.com
   ```

> **Note:** If neither `TERA_COOKIE` nor `TERA_API_URL` is set, the bot uses a default public API endpoint but results may be limited.

## ***Deploy Guide***

### Render (Recommended — free tier available)

1. Fork this repo
2. Go to [render.com](https://render.com) → New → Web Service → connect your fork
3. Render will auto-detect the `render.yaml` blueprint
4. Add your environment variables in the Render dashboard (see [Config Setup](#config-setup))
5. Deploy — the `/health` endpoint will be used for uptime checks

### Koyeb / Railway

1. Fork this repo
2. Create a new app pointing to your fork
3. Set all required environment variables
4. Use `python3 -m FZBypass` as the start command

### VPS / Docker

```bash
# Clone the repo
git clone https://github.com/rjriajul/FZBypassBot && cd FZBypassBot

# Copy and fill in your config
cp sample_config.env config.env
nano config.env

# Build and run
docker build -t fzbypass .
docker run --env-file config.env fzbypass
```

To stop:
```bash
docker ps           # get container ID
docker stop <id>
```

### Local / WSL (Development)

```bash
git clone https://github.com/rjriajul/FZBypassBot && cd FZBypassBot
cp sample_config.env config.env
# fill in config.env with your credentials

# Create venv inside WSL home (NTFS mounts don't support Linux permissions)

pip install -r requirements.txt
```
